## 核心指导思想与实施原则

1. **去经验主义，唯数据与事实是求**：
   - 彻底摒弃“我觉得没差距”、“凭感觉打”的主观推断，一切战术执行、对线优劣、英雄池评估均以量化数据和录像切片为基准。
2. **切片化、高频化、针对性训练**：
   - 杜绝全天无脑打 10 场垃圾时间占 80% 的普通训练赛，推行“10 分钟对线高频重置”、“20 分钟肉山攻防”等高密度专项切片训练。
3. **去情绪化、建设性复盘（Blameless Post-mortem）**：
   - 赛后复盘严禁人身攻击与推卸责任，专注审查“SOP 执行断点”与“信息流传递延迟”。
4. **权责明晰与职业化边界**：
   - 教练拥有 BP 最终决裁权与战术制定权，队长负责赛场瞬时指挥，分析师提供量化武器，各司其职，消除人情干预。
